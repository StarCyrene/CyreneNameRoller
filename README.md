## 功能

Dock 中的 **Roller** 是点名入口。在页面底部可切换八个工具，旧版翻牌链接仍然有效。

| 工具 | 适合什么时候用 |
| --- | --- |
| 滚动点名 / 翻牌点名 | 快速叫一人或多人，或请同学亲手翻牌；翻牌托盘按名单保存。 |
| 转盘点名 | 点一下转盘抽一人，指针停在实际抽中的人所在的扇区。 |
| 光轨穿梭 | 自选人数，一次抽齐不重复的姓名，投屏时可一起或逐个揭晓。关闭动效后直接显示。 |
| 座次寻光 | 按名单直接点名，临时缺席的人可以跳过。想按座位投屏时，再从 Excel 粘贴座位表，预览后生效。 |
| 流萤传灯 | 每传一次灯，才抽取并记录一位本轮没接过灯的人；适合轮流发言。 |
| 花笺藏名 | 把抽中的名字藏在字格里，按线索猜、逐字揭开，或直接看答案。每局只点一次名。 |
| 连星成诗 | 临时随机分组，组间人数最多差一人，可以复制结果，不改常设小组、不记点名。 |

**随机点名**
- 单人/多人模式，禁止重复（不放回抽取）
- 平衡算法：被抽中次数越少，下次概率越高
- 彩虹名称动画、English Mode

**翻牌点名**
- 3D 翻转卡牌动画
- 一键多抽（自动洗牌+翻牌）
- 收牌历史持久化、名单实时切换

**数据管理**
- 数据统计：抽取次数、概率、平衡概率
- 抽取记录：姓名、名单、来源、时间
- 名单管理：CRUD、批量删除（10秒撤销）、CSV/JSON 自动识别导入与可选格式导出
- 小组绑定随名单文件完整导入导出，人员 UUID 保持稳定
- SHA-256 密码保护

**抽奖模式**
- 滚动抽取、幸运转盘、花信盲盒、刮开好运。盲盒可点选拆开；刮刮卡支持鼠标、触屏或按键直接揭晓。
- 单抽或按库存批量抽取，抽前可看剩余件数与下一件奖品的概率；抽后可看完整结果。揭晓不再扣库存或多记一次历史。
- 先抽人员再批量分配奖品，包含库存校验与独立抽奖记录
- 多奖品单管理，支持 JSON/CSV 导入导出

**个性化**
- UI 缩放（50%-200%）、名字字体大小调整
- 桃粉、Windows Fluent 与智能生成的自定义浅/深主题
- 深色/浅色模式、中/英文切换、自动停止与多种结果强调动画

**插件系统**
- 支持在线安装、更新、卸载、启用和禁用 `.cnrp` 插件
- 插件可贡献独立 Dock 大型页面、宿主原生 Fluent 设置页面、动画包与 Canvas/WebGL 视觉层
- Web/Tauri 使用同一套权限化能力桥接，不支持的平台操作会明确降级
- 名单、抽取历史、统计与公平平衡参数以只读快照提供；新玩法只能通过宿主 `draw.execute` 发起抽取
- 抽取结果始终由宿主 CAF/安全随机逻辑决定，统计和历史只能由宿主追加，插件不能指定结果、改写或删除既有数据
- [官方插件模板、Fluent 组件画廊与 API 文档](https://github.com/Cyrene2008/CyreneNameRoller-Plugin-Template)

## 从源码开发

### 环境要求

- Node.js 22
- Bun 1.3.14
- Rust stable
- [Tauri 2 对应平台的系统依赖](https://v2.tauri.app/start/prerequisites/)

```bash
git clone https://github.com/StarCyrene/CyreneNameRoller.git
cd CyreneNameRoller
bun install
bun run dev
```

启动 Tauri 桌面客户端：

```bash
bun run tauri:dev
```

### 构建

构建 Web 版本：

```bash
bun run build
```

构建 Tauri 客户端：

```bash
bun run tauri:build
```

桌面安装包位于 `target/release/bundle/`。

Vue 3 + Vite + Tauri + Pinia + Vue Router + @iconify/vue (Fluent UI Icons)
