# Plugin API 1.5 Rewrite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the API 1.4 plugin runtime with a breaking API 1.5 desktop-process runtime that provides high-power UI, file, network, window, page-state, and operation-hook capabilities while keeping the Rust fairness core authoritative.

**Architecture:** API 1.5 plugins declare an explicit manifest contract and run in independently managed desktop processes over authenticated local JSON-RPC. The Vue host brokers permissions, navigation, page state, DOM/CSS, windows, and core reads/hooks; the Rust core alone validates and commits algorithm state, random state, lists, results, records, and statistics. Web loads only contributions supported by browser capabilities and returns structured unsupported results for desktop-only calls.

**Tech Stack:** Vue 3, Pinia, Vite, Tauri 2/Rust, JavaScript/TypeScript SDK, local JSON-RPC over stdio or socket, existing Node test scripts and Rust tests.
